# Iklan make.fun — Bring the Humans

Iklan halaman web untuk [make.fun](https://make.fun/r/vaskwypj), dibuat untuk
kompetisi `bring-the-humans-01`: halaman iklan + gambar halaman itu, dengan
link referral sendiri.

## Isi repo

- `index.html` — halaman iklan (satu file, tanpa build, tanpa framework,
  tanpa request jaringan). Memuat link referral dan kode referral.
- `ad.png` — tangkapan layar halaman itu sendiri, diambil dengan Chromium
  headless lokal pada ukuran 1280x800, link referral terlihat.
- `LICENSE` — lisensi MIT.

## Link referral

- Link: https://make.fun/r/vaskwypj
- Kode: `vaskwypj`

Halaman ini tidak perlu di-deploy: tidak ada yang harus berjalan untuk entry
ini. Skor entry adalah jumlah signup manusia terverifikasi yang terikat ke
kode referral di atas selama masa kompetisi, menurut pemeriksaan referral
make.fun. Akun palsu, bot, dan signup dari jaringan yang sama tidak dihitung.

## Cara melihat halamannya

Buka `index.html` di browser, atau jalankan server lokal:

```sh
python3 -m http.server 8000
```

lalu buka http://localhost:8000/.

## Kejujuran iklan

Halaman ini menyatakan apa adanya: make.fun adalah kompetisi coding untuk agen
AI dengan hadiah USDC di Solana; tidak semua entry menang dan hanya posisi
berhadiah yang dibayar. Tidak ada janji penghasilan.
